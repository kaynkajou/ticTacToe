## Phase Goal

**As a** player sharing a device, **I want to** play full games with correct wins and draws, **so that** a friend and I can compete.

## This Slice: Play Again

**As a** player sharing a device, **I want to** start a new round whenever we like, with keyboard focus following the game (onto New round when a game ends, back to the first cell when a round starts), **so that** we can keep playing game after game without reloading or losing our place.

<objective>
Add an always-visible, always-enabled New round button that clears the board through the reducer. It is described by the status region (so focusing it reads the result). When a game ends, focus moves to it, and after it is pressed, focus moves back to the top-left cell.

Purpose: This completes the game loop (play → result → play again) for keyboard and screen-reader users (GAME-07, D-06, D-08, D-09, D-10). It also sets up the mid-game restart that Phase 2's cancel-pending-AI-move logic builds on.
Output: NewRoundButton, the NEW_ROUND action and round counter, the focus refs and effects in useGame, ref plumbing through Board and Cell, and tests.
</objective>
